# Security Policy

## Supported versions

Only the latest release of be-BOP is supported. Keep your instance up to date.

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues, pull requests or discussions.

Report them privately through GitHub: open the [Security tab](https://github.com/be-BOP-io-SA/be-BOP/security) of this repository and click "Report a vulnerability". Only you and the maintainers can see the report.

If you cannot use GitHub, email security@be-bop.io.

Please include the affected release or commit, the steps to reproduce, and the impact you observed.

We acknowledge every report within 24 to 48 hours.

## Disclosure

We publish a security advisory 30 days after the release that contains the fix, so that instances have time to update. In exceptional circumstances, we may decide not to publish it.

Please do not disclose the vulnerability before the advisory is published, or without our agreement.

## Scope

This policy covers the code of this repository.

Test only on your own instance, run locally or with Docker. Never test on a shop you do not own, nor on be-BOP Cloud.

Out of scope:

- denial of service;
- social engineering;
- vulnerabilities in third-party services, such as Stripe, SumUp or payment nodes;
- dependency alerts without a demonstrated exploitation scenario.

## Recognition

If you wish, we credit you in the published advisory. be-BOP is free and open source software and does not offer financial rewards.
